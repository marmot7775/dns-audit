# Doc 103: five audit scopes, grouped by the visitor's question

The six scope pills group checks by record type. Regroup them by the
question a visitor is asking. Five scopes replace six: Complete
Audit, Email Deliverability, Email Security, DMARC Check, and DNS
Security. Transport Security and Security Scan go away. Old scope
keys keep working through a mapping so shared links, bookmarks, and
API callers do not break. This doc changes which checks each scope
runs and how the scopes are named. It changes no grading; per scope
grading is Doc 104.

## The new scopes

Keys, labels, and check sets. The check keys are the ones already in
`SCOPE_CHECKS` and `ALL_SCOPE_CHECK_KEYS` (`audit_engine.py` 306 to
333); no check is added or removed.

| key | label | checks |
|---|---|---|
| `complete` | Complete Audit | all twelve (`None`) |
| `deliverability` | Email Deliverability | dmarc, spf, dkim, mx |
| `email_security` | Email Security | dmarc, spf, dkim, mx, mta_sts, tls_rpt, dane, bimi |
| `dmarc` | DMARC Check | dmarc, spf, dkim |
| `dns_security` | DNS Security | dnssec, caa, dane, nameservers, ct |

`dmarc` and `complete` are unchanged. `dns_security` is `dns_infra`
renamed, same five checks. `deliverability` is new. `email_security`
is the old `email_full` set plus `dane`, so it covers everything
Transport Security did.

## Legacy keys

Every old key maps to the new scope that runs at least the same
checks:

| old key | maps to | why |
|---|---|---|
| `email_full` | `email_security` | same set plus dane |
| `transport` | `email_security` | mx, mta_sts, tls_rpt, dane are all in it |
| `dns_infra` | `dns_security` | renamed |
| `security_scan` | `complete` | its set spanned all three areas; complete is the only superset |

A legacy key is accepted anywhere a scope is accepted and is replaced
by the new key before anything else sees it. The audit result's
`scope` field, the cache key, the audit log, the PDF cover, the share
URL, and the lit pill all carry the new key. An invalid key still
returns 400 and the error lists the five new keys only.
